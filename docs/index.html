Try something without letting it in

In Claude Code
$ /desk-try "that scraping library everyone keeps posting about"

  hires a desk for it, installs everything INSIDE that desk,
  and writes down what it brought.

$ /desk-fire some-scraper --reason "done evaluating it"
$ node checks/run.mjs

  ⛔ 1 file(s) a desk brought in are living outside it
     some-scraper installed "cool-lib", which is at config/cool-lib.rc

     Firing that desk will not remove these.

You talk to the desk about the trial, not to your main session, so it keeps its own context and its own browser. When you fire it, a check confirms it left nothing behind.

What this is

A folder, a browser profile and an agent's context of its own, and a removal you can verify rather than hope about.

What this is not

A sandbox. It does not stop a determined script writing where it likes. For genuinely untrusted code, use a container.

Why a hook, not a rule

A written rule is something a model can talk itself out of at 2am with a customer waiting. A hook is not the model's decision.

It runs before the file exists

Not a report you read afterwards, if somebody runs it. The write is refused, and the tool call returns the reason.

Checked in both directions

A live desk with no way to send fails just as loudly. That one means somebody is being ignored.

Hiring refuses to guess

"quotes prices to customers" names both customers and internal figures, so it stops and asks rather than picking one.

Firing is the part everyone skips

It will not fire a live desk, or one anything still references. It archives instead of deleting, and hands back the steps no script can do.

Install

Nothing happens until you hire someone. With no desks/ directory there is nothing to have an opinion about, so it says so instead of showing you green ticks that mean nothing.

In Claude Code
$ /plugin install office-anything@office-anything
$ /desk-hire "someone who answers our Instagram DMs"

  reads it   → kind: channel
  issues     → a folder, its own Chrome, a reader, a voice standard
  withholds  → a sender. It starts dark.

  ⛔ chat: facts.md is still the stub. This desk knows nothing.

It fails on purpose. A new desk really does know nothing yet, so it says so and tells you what to write. Anything that hands you a finished-looking agent is training you to stop reading its output.
